## Location

`backend/src/loan-rate-changes/rate-change-inference.service.ts:116`

## Failure scenario

interestBookedSeparately is false whenever any consolidated payment has split interest. If a loan changes from $500 split installments to separate $450 principal transfers plus $50 interest expenses, hadSplitInterest remains true. A later inferred segment then persists approximately $450 as newPaymentAmount instead of leaving it null, causing timeline consumers to use a principal-only, non-amortizing payment.

## Recommended fix

Track the source of interest per payment or segment and suppress newPaymentAmount for each segment containing separately paired interest, rather than using one history-wide boolean.
