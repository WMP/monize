## Location

`backend/src/accounts/loan-payment-detector.service.ts:438`

## Failure scenario

The interest transaction query filters by user, account, category, and date but not transaction status. A categorized interest expense later marked VOID is still paired and summed into a payment, producing interest and inferred-rate values from a transaction that no longer affects the ledger.

## Recommended fix

Exclude VOID transactions when querying or processing separate-interest candidates, consistently with the application's balance queries.
