## Location

`frontend/src/lib/loan-history.ts:635`

## Failure scenario

Math.abs() discards the transaction direction. With a -100 interest expense and a +20 refund in the same category and pairing window, the code reports 120 of interest rather than the net 80.

## Recommended fix

Normalize expense direction without taking the absolute value of refunds, then aggregate signed amounts and discard only non-positive net interest where appropriate.
