## Location

`frontend/src/components/accounts/loan-detail/SavedScenariosPanel.tsx:104`

## Failure scenario

`describeScenario` calls `formatCurrency(scenario.recurringExtraAmount)` without the loan's `currencyCode`. For a USD loan viewed by a user whose default currency is CAD, a USD 200 overpayment is rendered as CAD 200 while the newly added comparison figures in the same row correctly use USD.

## Recommended fix

Pass `currencyCode` to `formatCurrency` when formatting `recurringExtraAmount`.
