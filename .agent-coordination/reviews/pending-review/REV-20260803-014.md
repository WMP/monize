## Location

`frontend/src/components/accounts/loan-detail/PayoffComparisonChart.tsx:78`

## Failure scenario

The new tooltip total adds monetary values directly. For three same-month overpayments of 100.00, 156.04, and 100.46, JavaScript produces 356.49999999999994 instead of 356.50. The zero-decimal tooltip formatter consequently displays 356 rather than the correctly rounded 357.

## Recommended fix

Accumulate integer ten-thousandths with Math.round(event.principal * 10000), then divide by 10000 when constructing the displayed point.
