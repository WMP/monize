## Location

`backend/src/accounts/loan-payment-detector.service.ts:442`

## Failure scenario

The query scopes interest only by source account, category, and date range. If two active loans are paid from the same chequing account and share an interest category, both loans retrieve both sets of interest expenses. For example, $100 interest for loan A and $200 for loan B near the same monthly payment date are summed as $300 when detecting either loan, producing false inferred rates.

## Recommended fix

Associate expenses with the specific loan using payment linkage or another loan-specific discriminator. If the ledger cannot disambiguate shared source/category activity, reject inference as ambiguous instead of summing it.
