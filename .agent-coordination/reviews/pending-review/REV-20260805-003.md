## Location

`frontend/src/components/accounts/loan-detail/OverpaymentSimulator.tsx:136`

## Failure scenario

The detection effect never clears `detectedExtra` when `accountId` changes. If loan A detects 250 and the same simulator instance is switched to loan B whose detection returns null or zero, the hint still claims B historically paid 250 extra; clicking “Use it” applies loan A's amount to B's simulation.

## Recommended fix

Reset `detectedExtra` to null whenever `accountId` changes before starting the new detection request, then populate it only from that request's result.
