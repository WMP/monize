## Location

`frontend/src/lib/loan-history.ts:306`

## Failure scenario

deriveCurrentInstallment selects the last REGULAR event without requiring principal > 0, while orphan interest expenses are emitted as REGULAR events. For a $100,000 loan at 12% with a $2,000 contractual payment and a final interest-only event of $1,000, the function returns $1,000. buildLoanProjectionInput then seeds a payment equal to first-period interest, so generateLoanSchedule immediately stalls instead of projecting with the contractual payment.

## Recommended fix

Select the last regular event with positive principal; fall back to contractualPayment when history contains only interest-only rows.
