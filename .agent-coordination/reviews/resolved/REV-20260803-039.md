## Location

`frontend/src/lib/loan-history.ts:859`

## Failure scenario

A timeout, authorization error, or backend 500 is converted to an empty list. The caller then uses analytic interest as though no actual interest transactions existed, so a transient fetch failure displays different cumulative interest and projections without surfacing an error.

## Recommended fix

Propagate the fetch failure or return an explicit unavailable state so callers can show an error instead of treating failed retrieval as no interest data.
