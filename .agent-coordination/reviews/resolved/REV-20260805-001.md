## Location

`frontend/src/components/accounts/loan-detail/LoanSummaryCards.tsx:86`

## Failure scenario

The payoff status uses `Math.abs(account.currentBalance) <= 0.01`. Because balances have four-decimal precision, a legitimate balance such as `-0.0099` is nonzero but is labelled “Paid off”; it can even be displayed as `$0.01` elsewhere on the same card.

## Recommended fix

Treat the loan as paid off only when the balance rounded to the database precision is zero, e.g. `Math.round(Math.abs(balance) * 10000) === 0`.
