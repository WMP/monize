## Location

`frontend/src/components/accounts/loan-detail/OverpaymentSimulator.tsx:81`

## Failure scenario

`formToPlan` emits a recurring overpayment whenever the amount is positive without checking that `startDate <= endDate`. For an amount of 200, start `2027-08-01`, and end `2026-08-01`, the UI treats the plan as active although no payment date can satisfy the interval, producing a scenario with no overpayments instead of rejecting the input.

## Recommended fix

Validate the date window before emitting the plan, surface an error when the start is after the end, and emit `null` or otherwise prevent simulation until corrected.
