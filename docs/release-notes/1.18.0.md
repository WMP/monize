# v1.18.0

## Mortgages

- **A Mortgage Type select** replaces the "Canadian Mortgage" and "Variable Rate" checkboxes on the mortgage form and in Set Up Payments. Choose **Annuity (Level Payment)** for a mortgage whose total payment is the same every period, including a variable-rate one, or **Canadian Fixed Rate** for a Canadian fixed-rate contract, whose interest compounds twice a year. Each option has a line of help saying how to recognise it.
- **Rate-Fixed Term for every mortgage.** The term used to appear only for Canadian mortgages. It is now offered for every mortgage and labelled as the period the rate is fixed for: a 5-year fixed rate, a UK fixed deal, a Dutch rentevaste periode, a German Zinsbindung. The reminder email before a term ends works for any mortgage that has one, and now says the current rate term is ending rather than that a renewal is coming.
- **"Record rate changes in Loan Details"** is shown for every mortgage when you edit it, not only a variable-rate one.
- **A wrong description is gone.** The Variable Rate option said it "uses monthly compounding". It never did: it only switched off Canadian semi-annual compounding, so a Canadian variable-rate mortgage was always calculated exactly like any other level-payment mortgage. That is what the Annuity type says it is.

### Linear and interest-only mortgages

- **Two new mortgage types.** **Linear (Constant Principal)** repays the same principal every period, so the total payment falls as the balance does, the usual arrangement in the Netherlands and elsewhere in Europe. **Interest Only** charges only the interest each period, and the whole balance is repaid in one final payment at the end of the amortization period.
- **What an extra repayment does**, for a linear mortgage: it either shortens the term (the principal part stays the same and the loan ends earlier; the default) or lowers the installment (the principal is spread over the payments left and the end date stays put). Your lender's statement after a repayment tells you which: if the principal part is unchanged, the term was shortened.
- **Each installment is worked out on its due date** from the balance owed and the rate in effect that day. These mortgages have no fixed payment, so Monize stores none: the form and Set Up Payments show the first installment, Loan Details shows the next one with its due date, and for an interest-only mortgage the final payment and its date are shown beside it. The overpayment simulator, the amortization and debt payoff reports and the AI assistant work from the same dated figures.
- **A rate change** moves only the interest of a linear or interest-only installment; the scheduled payment is repriced when you confirm the change, as before. A rate change on these mortgages cannot state a payment amount, because the installment is always worked out from the balance and the rate.
- These types need an amortization period, a first payment date and a regular payment frequency. Accelerated bi-weekly and weekly payments are a fraction of a level monthly payment, so they are offered only for the Annuity and Canadian Fixed Rate types.

### Not sure which type you have?

- **"Not sure? Enter a few installments"** under the Mortgage Type select, when you create a mortgage: type two or three consecutive installments from a statement (principal and interest, and the balance if you have it) and Monize suggests a type and says why. Nothing changes until you choose **Use This Type**.
- **Detect Mortgage Type** in the Rate History panel of Loan Details reads your latest posted installments at one rate and suggests a type from them, showing the installments it used. Accepting opens the account form with that type selected, for you to save. Installments recorded as a split of principal and interest are what it reads.

### What changes for an existing mortgage

Each mortgage is given the type its checkboxes already meant: Canadian and not variable becomes Canadian Fixed Rate, every other combination Annuity. Until you record a rate change, the payment, the principal and interest split, the effective annual rate and the payoff projection are the same as before.

**Known issue:** on a mortgage that had "Variable Rate" ticked and has no rate history recorded in Loan Details, saving the account clears that flag, and the payment history then shows today's rate on past payments that charged no interest, where it used to show none. Record the mortgage's rate changes in Loan Details to have each payment show the rate in effect on its date.

### Rate changes

- **A future-dated rate change** recalculates the payment from the balance on the date the new rate takes effect, so payments recorded before that date are counted, rather than from today's balance. The new payment can therefore differ from what the same change would have produced before.
- **Detected rate changes on a mortgage that was ticked both Canadian and Variable Rate** are now worked out from the interest by day count, the same way as every other Annuity mortgage, rather than by multiplying one period's rate by the payments per year. This affects only the rate changes Monize suggests from your payment history, never a recorded rate or a payment.

## For operators

- Database migrations add the mortgage type to each account and fill it from the two existing checkbox columns, add the linear prepayment setting, and add two checks: the prepayment setting is only set on a linear mortgage, and a linear or interest-only mortgage stores no fixed payment. They run with the usual migrations on upgrade and rewrite no existing row beyond the type. The checkbox columns are still written beside the type, so rolling back to 1.17.0 prices every mortgage as before. A mortgage saved on 1.18.0 is stored with "Variable Rate" cleared, so after a rollback that box shows unticked; the arithmetic is the same either way. 1.17.0 does not know the Linear and Interest Only types: it reads such a mortgage through the checkbox columns as a level-payment mortgage, with no stored payment.
