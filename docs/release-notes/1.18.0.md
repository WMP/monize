# v1.18.0

Mortgages are described by **one Mortgage type** instead of two checkboxes, and every mortgage can carry the period its rate is fixed for. No existing mortgage's payments, interest or projections change.

## Mortgages

- **A Mortgage Type select** replaces the "Canadian Mortgage" and "Variable Rate" checkboxes on the mortgage form and in Set Up Payments. Choose **Annuity (Level Payment)** for a mortgage whose total payment is the same every period, including a variable-rate one, or **Canadian Fixed Rate** for a Canadian fixed-rate contract, whose interest compounds twice a year. Each option has a line of help saying how to recognise it.
- **Rate-Fixed Term for every mortgage.** The term used to appear only for Canadian mortgages. It is now offered for every mortgage and labelled as the period the rate is fixed for: a 5-year fixed rate, a UK fixed deal, a Dutch rentevaste periode, a German Zinsbindung. The reminder email before a term ends works for any mortgage that has one, and now says the current rate term is ending rather than that a renewal is coming.
- **"Record rate changes in Loan Details"** is shown for every mortgage when you edit it, not only a variable-rate one.
- **A wrong description is gone.** The Variable Rate option said it "uses monthly compounding". It never did: it only switched off Canadian semi-annual compounding, so a Canadian variable-rate mortgage was always calculated exactly like any other level-payment mortgage. That is what the Annuity type says it is.

### What changes for an existing mortgage

- **Nothing numeric.** Each mortgage is given the type its checkboxes already meant: Canadian and not variable becomes Canadian Fixed Rate, every other combination Annuity. Payments, the principal and interest split, the effective annual rate and the payoff projection are the same as before.
- **Detected rate changes on a mortgage that was ticked both Canadian and Variable Rate** are now worked out from the interest by day count, the same way as every other Annuity mortgage, rather than by multiplying one period's rate by the payments per year. This affects only the rate changes Monize suggests from your payment history, never a recorded rate or a payment.
- **A future-dated rate change** recalculates the payment from the balance on the date the new rate takes effect, so payments recorded before that date are counted, rather than from today's balance.

## For operators

- A database migration adds the mortgage type to each account and fills it from the two existing checkbox columns; it runs with the usual migrations on upgrade. The checkbox columns are still written beside the type, so rolling back to 1.17.0 reads every mortgage as before.
